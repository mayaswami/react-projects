# 03 - React Advanced

A React practice project focused on advanced React concepts through separate demo pages.

## Topics Covered

- Project setup with Vite
- React Router setup
- Navigation using `NavLink`
- Separate demo pages for advanced React concepts

### Context API

- Understanding Prop Drilling
- Creating Context with `createContext()`
- Providing data using `Context.Provider`
- Consuming data with `useContext()`
- Sharing dynamic state through Context
- Updating Context state from child components
- Passing functions through Context (`login`, `logout`)
- Working with Multiple Contexts
- Basic Theme Toggle using `ThemeContext`
